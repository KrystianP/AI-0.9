# AI-0.9
Projekt służy rozwijaniu wiedzy i praktycznych umiejętności w zakresie AI,
automatyzacji oraz tworzenia efektywnych procesów. Jego ambicją jest osiągnięcie
poziomu pozwalającego należeć do 1% najbardziej świadomych i skutecznych
użytkowników AI na świecie — osób, które potrafią:

- korzystać z możliwości i korzyści oferowanych przez AI,
- tworzyć własne narzędzia wspierające codzienne życie i pracę,
- efektywnie zarabiać dzięki AI i automatyzacji.

Głównym celem projektu jest rozwój osobisty, budowanie rozwiązań pomagających
w efektywnym pomnażaniu kapitału oraz poprawa jakości codziennego życia.
